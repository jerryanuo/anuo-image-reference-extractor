ANUO / AI Film Skill

把一张图，拆成能继续生成的视觉资产。

Image Reference Extractor 面向 AI 影视和生图创作者，把上传图片中的人物、生物、道具、场景和风格 DNA 整理成可复用参考图。

前往 GitHub 查看使用手册

开始使用

安装后上传图片，直接对 Agent 说：

用 $image-reference-extractor 处理这个

你会得到

角色参考表面部、正面全身、三分之二角度、侧/背面角度。
生物参考表保留轮廓、材质、特殊结构和视觉气质。
道具参考表整理武器、产品、载具、装置和关键物件。
风格 DNA提取色彩、光影、材质、笔触、颗粒和氛围。
