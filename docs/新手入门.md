# ANUO Image Reference Extractor 新手入门

你可能已经能用 AI 生成图片，但一旦要做连续角色、AI 视频、MV 分镜或短片，就会遇到一个很具体的问题：

> 模型不是缺想象力，而是缺稳定、清楚、可复用的视觉参考。

`image-reference-extractor` 解决的是这一步。

## 第一次怎么用

上传一张图，然后输入：

```text
用 $image-reference-extractor 处理这个
```

如果你已经知道要拆什么，可以直接说：

```text
用 $image-reference-extractor 把图里的主角和怪物拆成 1:1 四宫格参考图。
```

```text
用 $image-reference-extractor 提取这个场景、道具和整体画风，后面我要做视频。
```

## 它会怎么判断

Skill 会把画面拆成五类信息：

| 类型 | 例子 | 常见产出 |
| --- | --- | --- |
| 人物 | 主角、配角、可辨认路人 | 角色四宫格参考表 |
| 生物 | 怪物、动物、机器人、精灵 | 生物多角度参考表 |
| 道具 | 武器、载具、产品、装置 | 道具多角度参考表 |
| 环境 | 房间、街道、森林、舞台 | 场景参考表 |
| 风格 DNA | 色彩、光影、材质、笔触 | 风格说明或风格板 |

## 不同环境下会发生什么

这个 Skill 会先判断当前 Agent 的能力：

| 当前环境 | 输出 |
| --- | --- |
| 能看图，也能生成图片 | 直接生成 1:1 参考表 |
| 能看图，但不能生成图片 | 输出资产清单、风格 DNA 和完整生图提示词 |
| 不能看图 | 不猜图，要求你补图、补描述或换到支持视觉的环境 |

## 常用输入

### 拆角色

```text
用 $image-reference-extractor 把这张图里的主角拆成角色参考图，保留脸、发型、衣服、比例和画风。
```

### 拆多个资产

```text
用 $image-reference-extractor 识别这张图里值得保留的角色、生物、道具和场景，分别做成参考图。
```

### 只提取风格

```text
用 $image-reference-extractor 只提取这张图的风格 DNA：色彩、光影、材质、笔触、氛围和负面限制。
```

### 给 AI 视频做前置资产

```text
用 $image-reference-extractor 处理这张关键帧。我要继续做 AI 视频，所以请优先拆出人物、场景和关键道具。
```

## 输出长什么样

角色和生物默认是 1:1 四宫格：

```text
左上：面部/头部特写
右上：正面全身
左下：三分之二全身
右下：侧面或背面角度
```

道具和场景也会整理成 1:1 参考表，方便继续喂给图像或视频模型。

## 注意

- 不要把这个 Skill 当成“裁图器”。它的价值是识别、整理和重建参考资产。
- 原图被遮挡、模糊或信息不足时，Agent 会保守补全，不会假装完全知道。
- 真正生成图片需要当前 Agent 环境支持图像生成能力；如果不支持，它会输出可复制的生图提示词，不会假装已经生成图片。
- 对受版权保护的角色、品牌、商标、电影 IP，请只在你有权使用的范围内操作。

## 下一步可以接什么

拆出资产后，你可以继续：

- 做关键帧：把角色、场景、道具组合成新画面。
- 做 AI 视频：把角色参考、场景参考和动作提示词交给视频模型。
- 做 MV 分镜：把人物参考、风格 DNA 和音乐情绪组合成九宫格分镜。
- 做短视频故事：从参考图里提取关系势能，设计 15 秒展示幕。
